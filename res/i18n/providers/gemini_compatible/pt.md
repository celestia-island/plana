# Compatível com Gemini

## Introdução

The Compatível com Gemini endpoint permite conectar-se to any service that implements the Google Gemini API specification. Use isto para auto-hospedados Gemini-compatible services or provedores alternativos.

## Organização

Esta é uma camada de compatibilidade endpoint that allows you to use the Gemini API format to connect to various terceiros or auto-hospedados services. Adequado para cenários que exigem the use of não oficiais Gemini endpoints.
