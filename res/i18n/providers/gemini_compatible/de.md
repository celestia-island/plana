# Gemini-kompatibel

## Einleitung

The Gemini-kompatibel Endpunkt ermöglicht die Verbindung to any Dienst that implements the Google Gemini API specification. Verwenden Sie dies für selbst gehostete Gemini-compatible Diensts or alternative Anbieter.

## Organisation

Dies ist eine Kompatibilitätsschicht Endpunkt that allows you to use the Gemini API format to connect to various Drittanbieter or selbst gehostete Diensts. Geeignet für Szenarien, die the use of nicht-offizielle Gemini Endpunkte.
