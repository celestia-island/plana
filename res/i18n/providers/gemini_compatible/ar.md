# متوافق مع Gemini

## مقدمة

The متوافق مع Gemini endpoint تتيح لك الاتصال to any service that implements the Google Gemini API specification. استخدم هذا لـ مستضاف ذاتياً Gemini-compatible services or مزودين بديلين.

## المنظمة

هذه طبقة توافق endpoint that allows you to use the Gemini API format to connect to various جهات خارجية or مستضاف ذاتياً services. مناسب لـ scenarios requiring the use of non-official Gemini endpoints.
