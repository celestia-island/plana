# Gemini Совместимый

## Введение

Совместимый с Gemini endpoint позволяет подключаться к любой службе, реализующей спецификацию Google Gemini API. Используйте для самостоятельно размещенных совместимых с Gemini служб или альтернативных провайдеров.

## Организация

Это endpoint уровня совместимости, который позволяет использовать формат API Gemini для подключения к различным сторонним или самостоятельно размещенным службам. Подходит для сценариев, требующих использования неофициальных endpoint Gemini.
