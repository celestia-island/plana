# Gemini Compatible

## Introduction

The Gemini Compatible endpoint allows you to connect to any service that implements the Google Gemini API specification. Use this for self-hosted Gemini-compatible services or alternative providers.

## Organization

This is a compatibility layer endpoint that allows you to use the Gemini API format to connect to various third-party or self-hosted services. Suitable for scenarios requiring the use of non-official Gemini endpoints.
