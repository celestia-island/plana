# Gemini Compatible

## Introducción

El endpoint Gemini Compatible le permite conectarse a cualquier servicio que implemente la especificación de la API de Google Gemini. Úselo para servicios autohospedados compatibles con Gemini o proveedores alternativos.

## Organización

Este es un endpoint de capa de compatibilidad que le permite usar el formato de la API de Gemini para conectarse a varios servicios de terceros o autohospedados. Adecuado para escenarios que requieren el uso de endpoints no oficiales de Gemini.
