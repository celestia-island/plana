# Anthropic Совместимый

## Введение

Совместимый с Anthropic endpoint позволяет подключаться к любой службе, реализующей спецификацию Anthropic API. Используйте для самостоятельно размещенных совместимых с Claude служб или альтернативных провайдеров.

## Организация

Это endpoint уровня совместимости, который позволяет использовать формат API Anthropic для подключения к различным сторонним или самостоятельно размещенным службам. Подходит для сценариев, требующих использования неофициальных endpoint Anthropic.
