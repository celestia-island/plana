# Anthropic Compatible

## Introduction

Le endpoint Anthropic Compatible vous permet de vous connecter à n'importe quel service qui implémente la spécification de l'API Anthropic. À utiliser pour les services auto-hébergés compatibles Claude ou les fournisseurs alternatifs.

## Organisation

Il s'agit d'un endpoint de couche de compatibilité qui vous permet d'utiliser le format de l'API Anthropic pour vous connecter à divers services tiers ou auto-hébergés. Convient aux scénarios nécessitant l'utilisation d'endpoints non officiels d'Anthropic.
