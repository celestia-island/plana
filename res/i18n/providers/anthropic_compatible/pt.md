# Compatível com Anthropic

## Introdução

The Compatível com Anthropic endpoint permite conectar-se to any service that implements the Anthropic API specification. Use isto para auto-hospedados Claude-compatible services or provedores alternativos.

## Organização

Esta é uma camada de compatibilidade endpoint that allows you to use the Anthropic API format to connect to various terceiros or auto-hospedados services. Adequado para cenários que exigem the use of não oficiais Anthropic endpoints.
