# متوافق مع Anthropic

## مقدمة

The متوافق مع Anthropic endpoint تتيح لك الاتصال to any service that implements the Anthropic API specification. استخدم هذا لـ مستضاف ذاتياً Claude-compatible services or مزودين بديلين.

## المنظمة

هذه طبقة توافق endpoint that allows you to use the Anthropic API format to connect to various جهات خارجية or مستضاف ذاتياً services. مناسب لـ scenarios requiring the use of non-official Anthropic endpoints.
