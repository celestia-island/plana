# Anthropic-kompatibel

## Einleitung

The Anthropic-kompatibel Endpunkt ermöglicht die Verbindung to any Dienst that implements the Anthropic API specification. Verwenden Sie dies für selbst gehostete Claude-compatible Diensts or alternative Anbieter.

## Organisation

Dies ist eine Kompatibilitätsschicht Endpunkt that allows you to use the Anthropic API format to connect to various Drittanbieter or selbst gehostete Diensts. Geeignet für Szenarien, die the use of nicht-offizielle Anthropic Endpunkte.
