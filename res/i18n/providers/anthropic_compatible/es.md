# Anthropic Compatible

## Introducción

El endpoint Anthropic Compatible le permite conectarse a cualquier servicio que implemente la especificación de la API de Anthropic. Úselo para servicios autohospedados compatibles con Claude o proveedores alternativos.

## Organización

Este es un endpoint de capa de compatibilidad que le permite usar el formato de la API de Anthropic para conectarse a varios servicios de terceros o autohospedados. Adecuado para escenarios que requieren el uso de endpoints no oficiales de Anthropic.
