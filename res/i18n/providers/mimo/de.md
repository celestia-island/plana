# Xiaomi MiMo

## Einleitung

Xiaomi MiMo is a series of AI Modells entwickelt by Xiaomi, entwickelt für coding and general-purpose tasks. The Token Plan bietens subscription-based access to MiMo Modells with OpenAI-compatible and Anthropic-compatible API Endpunkte across multiple regional clusters.

## Organisation

Xiaomi Corporation ist ein chinesisches electronics company that entwickelt AI Modells under the MiMo brand. MiMo Modells sind optimiert für coding assistance and unterstützen function calling, streaming, and other OpenAI-compatible Funktions.

## Token-Plan

The Token Plan is a subscription-based access Modell where API keys use the `tp-xxxxx` format (distinct from pay-as-you-go `sk-xxxxx` keys). Available clusters:

- China: `https://token-plan-cn.xiaomimimo.com/v1`
- Singapore: `https://token-plan-sgp.xiaomimimo.com/v1`
- Europe: `https://token-plan-ams.xiaomimimo.com/v1`

## Authentifizierung

The Token Plan uses a custom `api-key` header (not the standard `Authorization: Besindr`). The system automatically handles this when the auth type is set to `api-key`.
