# Xiaomi MiMo

## Введение

Xiaomi MiMo — это серия AI-моделей, разработанных Xiaomi, предназначенных для задач программирования и общего назначения. Token Plan предоставляет доступ к моделям MiMo по подписке с API-эндпоинтами, совместимыми с OpenAI и Anthropic, в нескольких региональных кластерах.

## Организация

Xiaomi Corporation — китайская компания по производству электроники, разрабатывающая AI-модели под брендом MiMo. Модели MiMo оптимизированы для помощи в программировании и поддерживают вызов функций, потоковую передачу и другие функции, совместимые с OpenAI.

## Тарифный план

Token Plan — это модель доступа на основе подписки, в которой API-ключи используют формат `tp-xxxxx` (в отличие от ключей `sk-xxxxx` с оплатой по мере использования). Доступные кластеры:

- Китай: `https://token-plan-cn.xiaomimimo.com/v1`
- Сингапур: `https://token-plan-sgp.xiaomimimo.com/v1`
- Европа: `https://token-plan-ams.xiaomimimo.com/v1`

## Аутентификация

Token Plan использует пользовательский заголовок `api-key` (не стандартный `Authorization: Bearer`). Система автоматически обрабатывает это, когда тип аутентификации установлен как `api-key`.
