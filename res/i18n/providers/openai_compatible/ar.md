# متوافق مع OpenAI

## مقدمة

The متوافق مع OpenAI endpoint تتيح لك الاتصال to any service that implements the OpenAI API specification. استخدم هذا لـ مستضاف ذاتياً GPT-compatible services or مزودين بديلين.

## المنظمة

هذه طبقة توافق endpoint that allows you to use the OpenAI API format to connect to various جهات خارجية or مستضاف ذاتياً services. مناسب لـ scenarios requiring the use of non-official OpenAI endpoints.
