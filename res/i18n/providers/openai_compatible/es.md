# OpenAI Compatible

## Introducción

El endpoint OpenAI Compatible le permite conectarse a cualquier servicio que implemente la especificación de la API de OpenAI. Úselo para servicios autohospedados compatibles con GPT o proveedores alternativos.

## Organización

Este es un endpoint de capa de compatibilidad que le permite usar el formato de la API de OpenAI para conectarse a varios servicios de terceros o autohospedados. Adecuado para escenarios que requieren el uso de endpoints no oficiales de OpenAI.
