# OpenAI-kompatibel

## Einleitung

The OpenAI-kompatibel Endpunkt ermöglicht die Verbindung to any Dienst that implements the OpenAI API specification. Verwenden Sie dies für selbst gehostete GPT-compatible Diensts or alternative Anbieter.

## Organisation

Dies ist eine Kompatibilitätsschicht Endpunkt that allows you to use the OpenAI API format to connect to various Drittanbieter or selbst gehostete Diensts. Geeignet für Szenarien, die the use of nicht-offizielle OpenAI Endpunkte.
