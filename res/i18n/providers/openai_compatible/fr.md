# OpenAI Compatible

## Introduction

Le endpoint OpenAI Compatible vous permet de vous connecter à n'importe quel service qui implémente la spécification de l'API OpenAI. À utiliser pour les services auto-hébergés compatibles GPT ou les fournisseurs alternatifs.

## Organisation

Il s'agit d'un endpoint de couche de compatibilité qui vous permet d'utiliser le format de l'API OpenAI pour vous connecter à divers services tiers ou auto-hébergés. Convient aux scénarios nécessitant l'utilisation d'endpoints non officiels d'OpenAI.
