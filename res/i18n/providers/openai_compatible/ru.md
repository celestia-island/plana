# OpenAI Совместимый

## Введение

Совместимый с OpenAI endpoint позволяет подключаться к любой службе, реализующей спецификацию API OpenAI. Используйте для самостоятельно размещенных совместимых с GPT служб или альтернативных провайдеров.

## Организация

Это endpoint уровня совместимости, который позволяет использовать формат API OpenAI для подключения к различным сторонним или самостоятельно размещенным службам. Подходит для сценариев, требующих использования неофициальных endpoint OpenAI.
