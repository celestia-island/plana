# Compatível com OpenAI

## Introdução

The Compatível com OpenAI endpoint permite conectar-se to any service that implements the OpenAI API specification. Use isto para auto-hospedados GPT-compatible services or provedores alternativos.

## Organização

Esta é uma camada de compatibilidade endpoint that allows you to use the OpenAI API format to connect to various terceiros or auto-hospedados services. Adequado para cenários que exigem the use of não oficiais OpenAI endpoints.
