# Qwen

## 소개

Qwen(통의천문)은 알리바바 클라우드의 대규모 언어 모델 시리즈로, 강력한 중국어 및 영어 기능을 제공합니다. 효율적인 추론부터 복잡한 추론까지 다양한 작업에 최적화된 여러 모델 크기를 제공합니다. 국내 버전과 글로벌 버전이 있습니다.

## 특징

- **통의천문**: 알리바바 클라우드 대규모 언어 모델 시리즈
- **이중 언어 우위**: 강력한 중영어 처리 능력
- **다양한 모델**: 효율적인 추론부터 복잡한 추론까지 다양한 선택
- **국내/국제**: 국내 버전과 글로벌 버전 제공
