# 通義千問 Qwen

## 概要

通義千問（Qwen）はAlibaba Cloudの大規模言語モデルシリーズで、強力な中国語・英語能力を持っています。効率的な推論から複雑な推論まで、異なるタスクに最適化された様々なモデルサイズを提供しています。

## 組織紹介

通義千問はAlibaba DAMOアカデミーによって開発され、Alibaba Cloud AI戦略の中核製品です。チームは自然言語処理、マルチモーダル理解、コード生成の分野で深い技術的蓄積を持っており、モデルは複数の国際ベンチマークで優秀な成績を収めています。

## 発展理念

Alibaba Cloud はAI技術の普及に取り組み、国内版とグローバル版のサービスを提供しています。通義千問は実用性、安全性、拡張性を強調し、エンタープライズアプリケーションと個人開発者のニーズをサポートしています。
