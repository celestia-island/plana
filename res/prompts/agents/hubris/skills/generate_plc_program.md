# Generate PLC Program

You generate **IEC 61131-3 Structured Text (SCL)** source code files that an
engineer can import into TIA Portal, compile, and download to the PLC.

## What You Generate

### 1. Safety Interlock Block (FC — Function)

For each discovered field with alarm thresholds, generate interlock logic:

```scl
// FC100: Safety Interlocks — Auto-generated by entelecheia
// Generated: 2026-06-17
// Based on: discovered corridor at 192.168.1.10 (S7-1500)

// Interlock: Temperature HH → Open cooling valve
IF "DB_Process".temperature_inlet > 80.0 THEN
    "DB_Control".cooling_valve := TRUE;
    "DB_Alarm".temp_hh_active := TRUE;
ELSIF "DB_Process".temperature_inlet < 75.0 THEN
    "DB_Control".cooling_valve := FALSE;
    "DB_Alarm".temp_hh_active := FALSE;
END_IF;

// Interlock: Pressure HH → Close inlet valve + Open relief valve
IF "DB_Process".pressure_outlet > 6.0 THEN
    "DB_Control".inlet_valve := FALSE;
    "DB_Control".relief_valve := TRUE;
    "DB_Alarm".pressure_hh_active := TRUE;
END_IF;
```

### 2. Alarm Logic Block (FC — Function)

Generate alarm detection with hysteresis:

```scl
// FC101: Alarm Detection with Hysteresis — Auto-generated
// HH threshold: 80.0, H threshold: 60.0, Hysteresis: 5.0

// Temperature alarm
IF "DB_Process".temperature_inlet >= 80.0 THEN
    "DB_Alarm".temp_hh := TRUE;
    "DB_Alarm".temp_h := TRUE;
ELSIF "DB_Process".temperature_inlet >= 60.0 THEN
    "DB_Alarm".temp_h := TRUE;
    "DB_Alarm".temp_hh := FALSE;
ELSIF "DB_Process".temperature_inlet < 55.0 THEN  // 60.0 - 5.0 hysteresis
    "DB_Alarm".temp_h := FALSE;
    "DB_Alarm".temp_hh := FALSE;
END_IF;
```

### 3. Data Acquisition Block (OB35 — Cyclic Interrupt)

Generate a cyclic data copy block for the monitoring system:

```scl
// OB35: Cyclic Data Acquisition (100ms) — Auto-generated
// Copies process values to DB_Monitor for evernight polling

"DB_Monitor".temperature_inlet := "DB_Process".temperature_inlet;
"DB_Monitor".pressure_outlet := "DB_Process".pressure_outlet;
"DB_Monitor".flow_rate := "DB_Process".flow_rate;
"DB_Monitor".valve_main_status := "DB_Process".valve_main;
"DB_Monitor".timestamp := "DB_Clock".system_time;
```

### 4. DB Definitions

Generate DB declaration source:

```scl
// DB1: DB_Process — Process Variables
DATA_BLOCK "DB_Process"
{ S7_Optimized_Access := 'TRUE' }
VERSION : 0.1
   STRUCT
      temperature_inlet : Real;   // °C — discovered at DB1.DBD0
      pressure_outlet : Real;     // MPa — discovered at DB1.DBD4
      flow_rate : Int;            // Nm³/h — discovered at DB1.DBW8
      valve_main : Bool;          // discovered at DB1.DBX10.0
   END_STRUCT;
BEGIN
   temperature_inlet := 0.0;
   pressure_outlet := 0.0;
   flow_rate := 0;
   valve_main := FALSE;
END_DATA_BLOCK
```

## Code Generation Rules

1. **Use the discovered field names** from `infer_semantics` — not generic names
1. **Include alarm thresholds** from the proposed alarm configuration
1. **Add hysteresis** (typically 5-10% of threshold range) to prevent chattering
1. **Include comments** with discovery metadata (address, confidence, evidence)
1. **Mark all auto-generated blocks** with a header comment block
1. **Safe defaults**: all valves default to CLOSED, all alarms default to inactive

## Output

Write to: `/workspace/generated_plc/`:

- `DB_Process.scl` — DB definition for process variables
- `DB_Alarm.scl` — DB definition for alarm states
- `DB_Control.scl` — DB definition for control outputs
- `DB_Monitor.scl` — DB definition for monitoring (polled by evernight)
- `FC_Safety_Interlocks.scl` — Safety interlock logic
- `FC_Alarm_Detection.scl` — Alarm detection logic
- `OB35_Data_Acquisition.scl` — Cyclic data acquisition
- `README_IMPORT.md` — Instructions for TIA Portal import

After writing all files, call `classic_software_engineering.code_verify` to verify syntax.

## Deployment Path

```text
Generated SCL files
  ↓
Engineer imports into TIA Portal
  ↓ (or via TIA Openness API for automation)
TIA Portal compiles to MC7 binary
  ↓
Download to PLC via PROFINET/USB
  ↓
PLC runs auto-generated safety interlocks + alarm logic
  ↓
evernight monitors DB_Monitor → entelecheia alarm pipeline
```

## TIA Openness Bridge (future — not in this skill)

For fully automated compile + download without manual TIA Portal interaction,
a Windows-side bridge service is needed:

```text
entelecheia → HTTP POST /compile {scl_source}
  → Windows C# service (TIA Openness COM API)
    → Opens TIA Portal project
    → Creates/updates blocks from SCL
    → Compiles
    → Downloads to PLC
    → Returns {success, errors}
```

This bridge requires:

- Windows machine with TIA Portal V16+ installed
- TIA Openness API license (included with TIA Portal Professional)
- .NET 6+ runtime
- Network access to the PLC

Estimated effort: 1-2 weeks for a basic bridge (compile + download, no diff/merge).
