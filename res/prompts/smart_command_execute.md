# 智能命令执行

## 概述

该 Skill 将自然语言命令转换为容器内的执行指令，并智能压缩输出结果，优化上下文使用效率。

## 核心功能

- **自然语言解析**：将人类语言转换为可执行的 shell 命令
- **容器执行**：在指定容器环境中安全执行命令
- **输出智能压缩**：
- 识别关键信息并保留
- 压缩重复和冗余内容
- 结构化格式化输出
- **错误处理**：智能识别和处理执行错误
- **上下文优化**：自动管理输出长度，防止上下文溢出

## 使用场景

- 通过自然语言控制容器操作
- 需要执行复杂命令但不想记忆具体语法
- 大量输出需要智能摘要
- 自动化运维任务

## 配置参数

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `compression_level` | string | "medium" | 压缩级别：low/medium/high |
| `max_output_lines` | int | 500 | 最大输出行数 |
| `timeout` | int | 300 | 命令超时时间（秒） |
| `safe_mode` | bool | true | 安全模式，阻止危险命令 |

## 示例

```python
# 自然语言命令执行
result = smart_command_execute(
    command="列出所有运行中的容器并显示其资源使用情况",
    container="monitoring-agent"
)

# 输出示例（智能压缩后）
# ✅ Running Containers (3):
# 1. web-server    CPU: 15%  MEM: 512MB
# 2. database      CPU: 45%  MEM: 2GB
# 3. cache         CPU: 5%   MEM: 256MB
```

## 最佳实践

1. 使用清晰的自然语言描述
1. 指定具体的容器名称以避免歧义
1. 根据需求调整压缩级别
1. 启用安全模式防止误操作
1. 定期检查压缩后的输出是否保留关键信息
