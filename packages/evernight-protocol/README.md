# plana_evernight_protocol

Wire DTOs for the evernight **Tier 3 `protocol.*` JSON-RPC plugin contract**:
the internally tagged transport/address payloads and the five method
parameter/result shapes shared by the evernight gateway and third-party
protocol-plugin authors, defined once so that every side of the contract has
one source of truth.

**Rust crate** `plana_evernight_protocol`: consumed via git dependency
(see below); not published to crates.io.

**npm package** [`@celestia-island/plana-evernight-protocol`](https://www.npmjs.com/package/@celestia-island/plana-evernight-protocol):
a *types-only* package carrying the generated `.d.ts` declarations, with no
runtime code.

## The five methods

A Tier 3 plugin is an external process speaking JSON-RPC 2.0 (over WebSocket
or a Unix domain socket). It answers exactly five methods; the method-name
constants give both sides one spelling:

| Method constant | Method | Params → Result |
| --- | --- | --- |
| `PROTOCOL_CONNECT_METHOD` | `protocol.connect` | `ConnectParamsDto` → `ConnectResultDto` |
| `PROTOCOL_READ_METHOD` | `protocol.read` | `ReadParamsDto` → `ReadResultDto` |
| `PROTOCOL_WRITE_METHOD` | `protocol.write` | `WriteParamsDto` → `WriteResultDto` |
| `PROTOCOL_PING_METHOD` | `protocol.ping` | `PingParamsDto` → `PingResultDto` |
| `PROTOCOL_PROBE_METHOD` | `protocol.probe` | `ProbeParamsDto` → `ProbeResultDto` |

## DTO surface

Payload enums (serde internal tagging on `"kind"`, lowercased variant names,
so TypeScript consumers get a plain discriminated union):

| Type | Role |
| --- | --- |
| `TransportInfoDto` | `Tcp { host, port }` \| `Serial { port, baud }` — how to reach a device |
| `DataAddressDto` | `Modbus { station, fc, address, count }` \| `S7 { db_number, offset, length }` \| `Mc { device, head_address, count }` \| `Raw { address, size }` — where to read/write |
| `WriteVerificationDto` | `"confirmed"` \| `"unconfirmed"` \| `"unknown"` — tri-state write verification |

Param/result structs per method:

| Method | Params | Result |
| --- | --- | --- |
| `protocol.connect` | `{ transport }` | `{ connected }` |
| `protocol.read` | `{ address }` | `{ raw, latency_us }` |
| `protocol.write` | `{ address, data }` | `{ confirmed, verification? }` |
| `protocol.ping` | `{}` | `{ reachable }` |
| `protocol.probe` | `{ transport }` | `{ protocol, confidence }` |

The JSON literals pinned by `tests/wire_shapes.rs` *are* the contract;
changing one is a wire break that must be coordinated with evernight's
anchor tests and the Tier 3 guide's interface table.

## Rust consumption (git dependency)

The crate follows plana's workspace version line and is consumed via a git
reference — the exact line evernight's workspace uses:

```toml
[dependencies]
plana_evernight_protocol = { version = "0.1", git = "https://github.com/celestia-island/plana.git", branch = "master" }
```

```rust
use plana_evernight_protocol::{TransportInfoDto, PROTOCOL_CONNECT_METHOD};

let transport = TransportInfoDto::Tcp {
    host: "192.0.2.10".to_string(),
    port: 502,
};
// Serializes to {"kind":"tcp","host":"192.0.2.10","port":502}
let wire = serde_json::to_string(&transport).unwrap();
assert_eq!(wire, r#"{"kind":"tcp","host":"192.0.2.10","port":502}"#);
assert_eq!(PROTOCOL_CONNECT_METHOD, "protocol.connect");
```

## TypeScript consumption (npm)

```sh
pnpm add @celestia-island/plana-evernight-protocol
```

```ts
import type {
  ConnectParamsDto,
  TransportInfoDto,
} from "@celestia-island/plana-evernight-protocol";

const params: ConnectParamsDto = {
  transport: { kind: "tcp", host: "192.0.2.10", port: 502 } satisfies TransportInfoDto,
};
```

The package is **types-only**: `types` resolves to `index.d.ts` (which
re-exports `bindings/evernightProtocol.d.ts`), `main` points at an empty
placeholder, and the `files` whitelist ships no raw `.ts`.

## Keeping the bindings in sync

`bindings/evernightProtocol.ts` is generated by [ts-rs](https://github.com/Aleph-Alpha/ts-rs)
whenever `cargo test` runs (the 13 `#[ts(export)]` types merge into that one
file). `bindings/evernightProtocol.d.ts` is a byte-identical copy that ships
to npm; `tests/bindings_dts.rs` fails when the two drift. After regenerating:

```sh
cp bindings/evernightProtocol.ts bindings/evernightProtocol.d.ts
```
