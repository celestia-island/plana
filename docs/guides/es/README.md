> **Versión 0.1.0** — Usado por [entelecheia](https://github.com/celestia-island/entelecheia) y [shittim-chest](https://github.com/celestia-island/shittim-chest).

Tipos de mensajes JSON-RPC 2.0, taxonomía de agentes (14 variantes), ~100 tipos de parámetros WebSocket. Bindings TypeScript auto-generados mediante `ts-rs`.

## Uso

**Rust:**
```toml
[dependencies]
arona = { git = "https://github.com/celestia-island/arona.git", branch = "master" }
```

**TypeScript:**
```bash
pnpm add @celestia-island/arona
```
